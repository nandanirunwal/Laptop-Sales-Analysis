# Laptop Sales Analysis Dashboard

## Project Overview
This project is a Laptop Sales Analysis Dashboard developed using Microsoft Power BI. It analyses laptop listing data and presents insights about brands, prices, processors, RAM, storage, graphics, display specifications and operating systems.

## Dataset
- Total Records: 1,020
- Total Columns: 29
- Dataset Format: CSV

## Objectives
- Analyse laptop brands and their specifications.
- Explore laptop price distribution.
- Identify commonly listed operating systems and processors.
- Analyse RAM, storage, graphics and display features.
- Present insights through interactive Power BI dashboards.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- CSV Dataset

## Dashboard Pages

### Page 1 – Laptop Sales Overview
Provides an overview of laptop data using KPI cards and charts.

### Page 2 – Technical / Product Analysis
Explores laptop specifications and their relationships through visualisations.

### Page 3 – Product Insights
Displays key product insights using cards highlighting commonly occurring laptop attributes.

## Key Findings
- Most common CPU core count: 8 cores.
- Most common thread count: 12 threads.
- Most common graphics memory: 4 GB.
